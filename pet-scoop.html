Ad analytics

Auto-updating from Meta ✓ — spend, reach, frequency, and leads refresh themselves every few hours.
Ad numbers pull straight from Meta automatically once connected below. Nothing to type, ever.
Connect Meta auto-sync (one time, ~15 min)
  1. Create a Meta app. Go to developers.facebook.com → My Apps → Create App → type Business → name it "PetScoop Sync" → link your Business portfolio.
  2. Make a system user. Go to business.facebook.com/settings → Users → System users → Add → name "petscoop-bot", role Admin.
  3. Give it your ad account. On the system user → Assign assets → Ad accounts → pick your PetScoop ad account → enable View performance.
  4. Generate the token. On the system user → Generate token → pick the "PetScoop Sync" app → expiration Never → permission ads_read → Generate. Copy the long token somewhere safe.
  5. Get your ad account ID. In Ads Manager the URL has act=1234567890, or Business Settings → Ad accounts shows the ID.
  6. Add two Vercel env vars (scale.vertise project → Settings → Environment Variables):
    META_TOKEN = the token from step 4
    META_AD_ACCOUNT = act_ + your ID (e.g. act_1234567890)
    Then Redeploy (Deployments → ⋯ → Redeploy).
  7. Reopen this app. A green "Auto-updating from Meta ✓" banner appears above, and spend, reach, impressions, frequency, and Meta leads refresh themselves every few hours. Done forever.

Sync

Every phone that opens this link shares the same live pipeline automatically. Nothing to configure here. Your partner just opens scalevertise.app/pet-scoop and sees your leads.
One-time database switch (you only)
  1. Turn on the database. In Vercel → your scale.vertise project → Storage tab → Create Database → KV (Upstash Redis) → Connect to this project → then Redeploy (Deployments → ⋯ → Redeploy). That's the whole setup.
  2. Tap Send test lead above — a "Test Lead" pops into your Leads tab within a couple seconds. Delete it after. That means it's live for both phones.
Zapier → Meta leads (advanced)
  1. Trigger = Facebook Lead Ads → New Lead (your Pet Scoop page + form). Action = Webhooks by Zapier → POST:
  2. URL: https://scalevertise.app/api/leads
  3. Payload Type: Json · Data:
    token = petscoop-live-7Kq2mZ9fLxW4
    action = newlead
    name = First Name
    phone = Phone Number
    source = Ad Name
    created = Created Time
  4. Publish the Zap. Every Meta lead lands here in under a minute, deduped by phone.
