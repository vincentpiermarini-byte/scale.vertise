One-time database switch (you only)
  1. Turn on the database. In Vercel → your scale.vertise project → Storage tab → Create Database → KV (Upstash Redis) → Connect to this project → then Redeploy (Deployments → ⋯ → Redeploy). That's the whole setup.
  2. Tap Send test lead above — a "Test Lead" pops into your Leads tab within a couple seconds. Delete it after. That means it's live for both phones.
Zapier → Meta leads (advanced)
  1. Trigger = Facebook Lead Ads → New Lead (your Pet Scoop page + form). Action = Webhooks by Zapier → POST:
  2. URL: https://scalevertise.app/api/leads
  3. Payload Type: Json · Data:
    token = petscoop-live-7Kq2mZ9fLxW4
    action = newlead
    name = First Name
    phone = Phone Number
    source = Ad Name
    created = Created Time
  4. Publish the Zap. Every Meta lead lands here in under a minute, deduped by phone.
