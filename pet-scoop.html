Sync

Connect a free Google Apps Script so Meta leads flow in automatically through Zapier, and your statuses back up to a Google Sheet.
Setup guide (one time, ~5 min)
  1. Go to script.google.com → New project. Delete the sample code, paste the script below, and set TOKEN at the top to your secret.
  2. Deploy → New deployment → Web app. Execute as: Me. Who has access: Anyone. Copy the web app URL.
  3. Paste the URL + your secret above and hit Save & test.
  4. In Zapier: trigger = Facebook Lead Ads → New Lead (your Pet Scoop page + form). Action = Webhooks by Zapier → POST.
    URL: your web app URL · Payload type: json
    Data fields:
    token = your secret
    action = newlead
    name = Full Name (or First Name)
    phone = Phone Number
    source = Ad Name
    created = Created Time
  5. Turn the Zap on. Done: every Meta lead lands here in under a minute, and this app refreshes itself every 20 seconds.
